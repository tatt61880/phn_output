Installation instructions

v0.0.6

2012-05-04 Download ZIP

Added thrusters for SVG line elements with start markers. Reduced unnecessary nodes when converting Bézier curves and other paths to polygons. Fixed a path parser bug that could produce incorrect polygons.

v0.0.5

2012-04-19 Download ZIP

Switched back to xml.etree.ElementTree and removed the dependency on sorted() for Python 2.3. ElementTree was not included in the Python 2.3 standard library. Fixed springs and hinges that failed to attach to two objects.

v0.0.4

2011-02-28 Download ZIP

Added support for non-intersecting compound paths. Fixed attachment and hole detection. Switched to xml.dom.minidom, tested with Python 2.4.4, and refactored the code. Updated the example drawing, grid and snapping settings.

v0.0.3

2011-02-19 Download ZIP

Added motors, self-intersecting paths, SVG polygons, and springs made from two-point paths. Exported scenes can now include the original SVG as a comment. Plane color now uses the fill, with a special case for an empty fill (none).

Improved arc approximation, added Python 3 support, fixed several errors, and updated example.svg.

v0.0.2b

2011-02-13 Download ZIP

Disabled plane borders and fixed ellipse conversion.

v0.0.2a

2011-02-13 Download ZIP

Fixed the center of mass for shapes with holes.

v0.0.2

2011-02-13 Download ZIP

Added springs, hinges, and laser pens. Reduced the number of exported coordinates and simplified the example drawing. The converter can run independently of Inkscape with Python. Improved warnings and fixed plane color.

v0.01

2011-02-09 Download ZIP

Initial release. Exported polygons, boxes, circles, planes, and tracers.
